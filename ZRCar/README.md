# ZRCar — compact ZRSense-only robot

The mini Zone Robotics robot. One [ZRSense](../ZRSense/) board, a compact chassis, ready to drive from your browser. This is the first robot Zone Robotics is shipping.

## What lives here

Assembly notes, chassis files, media and any bill-of-materials for the ZRCar build.
