# ZRSense — ESP32-S3 sensing board

Zone Robotics' ESP32-S3 Sense board. Hosts the third-party Seeed XIAO ESP32-S3 Sense module and carries the camera, sensors, RGB status lighting and I²C connections.

## What lives here

Datasheets, pinouts, board renders, mechanical drawings, and any media specific to ZRSense.

## Product page

<https://home.zonerobotics.com/products/zrsense>

## Runs ZROS

The board is built to run [ZROS](../ZROS/) — the free Zone Robotics firmware.
