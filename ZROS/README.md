# ZROS — Zone Robotics local firmware

Free ESP32-S3 firmware. Flash it onto a Seeed XIAO ESP32-S3 Sense (or compatible) and you have a working Zone Robotics robot with camera streaming, motor/servo control, RGB status and a browser-based programmer — all running on the device.

## Download

Firmware binaries will land here as they're released. Grab the latest version and follow the flashing guide.

## Flash it

Community guide with the ESP Download Tool:
<https://discourse.zonerobotics.com/t/how-to-flash-esp32s3-sense-with-xiao-flash-download-tool/26>

## What's included

- Local web control interface
- Local drag-and-drop programmer
- Camera + video streaming (MJPEG)
- Motor + servo control channels
- Configurable RGB status LEDs
- Sensor input readouts
